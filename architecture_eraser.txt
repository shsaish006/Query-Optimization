// --- Data Flow & Connections ---

// 1. User Input Flow
Glassmorphic UI > Routing Engine: Submits SQL Query
Routing Engine > SQLGlot Parser: Forwards Query

// 2. Parsing Flow
SQLGlot Parser > RA Tree Constructor: Generates AST
RA Tree Constructor > Graph Renderer: Generates Initial Visual Tree

// 3. Optimization Flow
RA Tree Constructor > Optimization Engine: Unoptimized RA Tree
Optimization Engine > Recursive Estimator: Sends Optimized RA Tree

// 4. Estimation Flow
Recursive Estimator > Table Statistics: Fetches Mock Data
Recursive Estimator > Metrics Extractor: Computes Tree Costs
Metrics Extractor > Metrics Dashboard: Formats Absolute & % Costs

// 5. Output Flow
Graph Renderer > Glassmorphic UI: Renders SVG Graph
Metrics Dashboard > Glassmorphic UI: Updates UI Cards
